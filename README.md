## ✨ Features

- 📄 **Multi-format Support** - Open `.pdf`, `.docx`, `.pptx`, `.txt` files
- 🔄 **Auto PDF Conversion** - All documents auto-convert to PDF
- 🤖 **Offline AI Chat** - RAG-powered AI answers from your documents
- 📚 **Split Panel View** - Document viewer + AI chat side by side
- 🌙 **Dark/Light Mode** - Toggle themes
- 🌍 **Bilingual** - English & Amharic (አማርኛ)
- 🔔 **Auto Updates** - GitHub release checker built-in
